Methodology and data notes

Transparent interpretation of satellite active-fire products.

Data harmonization

MODIS and VIIRS observations are mapped to a shared set of fields: sensor, satellite, acquisition time, latitude, longitude, confidence, FRP and detection type. UTC timestamps are retained; local display times can be derived for a chosen region.

Confidence

VIIRS commonly uses low, nominal and high categories. MODIS confidence values are numeric. This prototype uses a simple display grouping; preserve original confidence values and confirm product-specific thresholds before scientific interpretation.

Cross-sensor interpretation

Nearby detections can be candidate matches, not proof that both sensors observed the same physical fire. Spatial and temporal tolerances should be documented and tested for the study region.

Important limitations

Active-fire products can miss fires due to clouds, overpass timing, small fire size, canopy cover and other factors. A hotspot is a pixel-level thermal anomaly, not a fire perimeter or burned-area estimate. This application visualizes historical files supplied by the user and is not an operational emergency alert service.

Data source

NASA Fire Information for Resource Management System (FIRMS). Use the product documentation accompanying the downloaded archive.
